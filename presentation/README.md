# Презентация

25 HTML-слайдов к докладу «Масштабирование интеллекта через мультиагентность — работает ли?». [Источники](sources.html) и записанные траектории включены. Научные и индустриальные кейсы, SQL-эксперимент и его ограничения разобраны в материалах.

## Запуск

Из корня репозитория с установленными зависимостями:

```bash
uv run python -m presentation.serve
```

Слайды: `http://127.0.0.1:8768/index.html`. Живое демо: `http://127.0.0.1:8769/live.html`. Статические слайды и записанная траектория работают и при открытии `index.html` напрямую. Живой запуск требует локальную тестовую PostgreSQL и модель, настроенную в `.env`. Начните с `.env.example` в корне репозитория.

Стрелки, Space и PageUp/PageDown переключают слайды. `F` включает полный экран, `O` — обзор, `S` — источники. Встроенный проигрыватель демонстрирует Single, Orchestrator, Swarm и Board Swarm. Живой чат принимает свой SELECT к тестовому fixture и показывает инструменты, передачи управления и проверки.

## Данные

Таблица 3×3 основана на последнем серверном повторе: 27 финальных SQL, по 10 парных замеров каждого. [Отчёт](materials/report.md), [все пары](materials/samples.jsonl), [манифест](materials/manifest.json) и [финальные SQL](../data/server-replay/candidates/) опубликованы рядом с презентацией. Статистика токенов и оценка стоимости находятся в `metrics.json` и `cost-estimate.json`. Для Luna Single расход неполон из-за одного вызова без usage.

Живое демо и записанная траектория не входят в серверную матрицу 3×3.
